# Phase 2: RAG from Scratch

Build a complete Retrieval-Augmented Generation pipeline from the ground up, without any frameworks.

## Key Concepts

- Document loading and text chunking strategies
- Embeddings with sentence-transformers
- Vector storage and similarity search with ChromaDB
- Retrieval-augmented prompt construction
- End-to-end RAG pipeline

## Scripts

- `01_chunking.py` — Load documents and split into chunks
- `02_embeddings.py` — Generate and explore embeddings
- `03_vector_store.py` — Store and query vectors with ChromaDB
- `04_rag_pipeline.py` — Full RAG pipeline tying it all together
