# Phase 1: LLM Basics

Learn how LLMs work at the API level by making raw HTTP calls — no frameworks, no abstractions.

## Key Concepts

- Ollama REST API (chat completions, streaming)
- Prompt engineering patterns (system prompts, few-shot, chain-of-thought)
- Structured output with Pydantic and JSON mode
- Temperature, top-p, and other generation parameters

## Scripts

- `01_hello_llm.py` — First API call to Ollama
- `02_prompt_patterns.py` — System prompts, few-shot examples, chain-of-thought
- `03_structured_output.py` — JSON mode + Pydantic validation
